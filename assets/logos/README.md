# Logo assets

`github.png` is the default static-logo-watermark image (GitHub's mark, 280×280).
It's overlaid in a corner of the video, scaled and opacity-adjusted per `LOGO_*`
settings (see `.env.example`). Any PNG or JPEG works — point `LOGO_FILE` at your own.

The GitHub logo is a trademark of GitHub, Inc.; it's bundled here only as a demo
default. Replace it with your own brand for real use.
